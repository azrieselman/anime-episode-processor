# AEP 1.0.0-beta4

Fourth public beta of Anime Episode Processor — a 100% local Windows desktop app
for upscaling, frame-interpolating, and re-encoding anime episodes with full
preservation of subtitles, chapters, attachments, fonts, and metadata.

> **Beta** means: the pipeline remains feature-complete with a growing unit test
> suite on Windows, but field coverage is still limited. Please file bugs at the
> issue tracker — see `Help → Report Issue` in the GUI.

## Downloads

* **`AEP-Setup-1.0.0-beta4.exe`** — Windows installer (recommended for end
  users). Lightweight (~75–150 MB depending on bundle); on first launch the GUI
  offers to download and SHA256-verify the pinned third-party tools (~2 GB) into
  `%LOCALAPPDATA%\AEP\tools\`.
* **`anime_episode_processor-1.0.0b4-py3-none-any.whl`** — Python wheel for
  pip install. Run `python scripts/fetch_tools.py` afterward (or just launch
  `aep-gui` and let it fetch on its own).
* **`anime_episode_processor-1.0.0b4.tar.gz`** — sdist.

## Highlights since 1.0.0-beta3

* **Broader hardware encode**: Intel QSV, AMD AMF, and D3D12 / Vulkan encoder
  families alongside NVENC, with expanded preset designer knobs and recommender
  coverage.
* **FFmpeg 8.1.1 full**: repinned gyan.dev full build for wider encoder / filter
  support (including VMAF when available).
* **Benchmark** tab: run a short segment through a preset and compare results;
  optional VMAF scoring when `libvmaf` is in the FFmpeg build.
* **RamDisk** tab + ImDisk helpers for configuring a Windows RAM disk used by
  frame-heavy pipeline stages.
* **Batch frame accounting**: packet-accurate duration / `decodable_end_s` from
  FFProbe, plus batch timing utilities so decode/interpolate counts stay
  reconciled when container duration is inflated.
* **RIFE Vulkan retry**: detect `vkQueueSubmit failed` and retry interpolation
  up to three times.
* **GUI**: refreshed dark theme, simplified sidebar (Job Config removed),
  safer custom FFmpeg argv quoting.
* **Cleanup**: removed Anime4KCPP-legacy and unused built-in presets; default
  `anime_balanced` uses Anime4K ARTCNN 2x + RIFE v4.25.

## Known limitations

* `02_sample_bench` pipeline-stage smart auto-tuning — post-beta (Benchmark tab
  is a manual segment tool, not auto-preset selection).
* `av1_nvenc` → `hevc_nvenc` automatic fallback on encode failure.
* macOS / Linux ports.
* Out-of-process worker broker (today everything runs in-process; the
  service layer is already abstracted for the eventual move).
* Code-signed Windows installer.

## Hardware

Optimized for NVIDIA RTX 3000-series and newer (CUDA / NCNN-Vulkan / TensorRT),
with first-class paths for Intel (QSV) and AMD (AMF) as well as D3D12 / Vulkan
encoders where the FFmpeg build exposes them. Older NVIDIA cards work for the
CPU-encoder presets (libx264/libx265). NVENC AV1 requires Ada-class (RTX 4000+)
hardware.

## How to tag this release

```powershell
git checkout main
git pull
git tag -a v1.0.0-beta4 -m "AEP 1.0.0-beta4"
git push origin v1.0.0-beta4
```

The `release.yml` GitHub Actions workflow then builds the sdist + wheel and
attaches them to the auto-created Release page (marked as a pre-release).

The Windows installer (`AEP-Setup-1.0.0-beta4.exe`) is built locally with
`python scripts/build_installer.py` and uploaded manually to the release.
