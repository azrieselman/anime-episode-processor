# AEP 1.0.0-beta2

Second public beta of Anime Episode Processor — a 100% local Windows desktop app
for upscaling, frame-interpolating, and re-encoding anime episodes with full
preservation of subtitles, chapters, attachments, fonts, and metadata.

> **Beta** means: the pipeline remains feature-complete with a growing unit test
> suite on Windows, but field coverage is still limited. Please file bugs at the
> issue tracker — see `Help → Report Issue` in the GUI.

## Downloads

* **`AEP-Setup-1.0.0-beta2.exe`** — Windows installer (recommended for end
  users). Lightweight (~75–150 MB depending on bundle); on first launch the GUI
  offers to download and SHA256-verify the pinned third-party tools (~2 GB) into
  `%LOCALAPPDATA%\AEP\tools\`.
* **`anime_episode_processor-1.0.0b2-py3-none-any.whl`** — Python wheel for
  pip install. Run `python scripts/fetch_tools.py` afterward (or just launch
  `aep-gui` and let it fetch on its own).
* **`anime_episode_processor-1.0.0b2.tar.gz`** — sdist.

## Highlights since 1.0.0-beta1

* **Duplicate-frame handling**: decode can compact perceptual duplicates for
  NCNN stages; upscale/interpolate expand so the encoded timeline matches the
  full decoded frame count.
* **Help → Check for Updates** against GitHub releases (prereleases included).
* **Verify Tools** and related in-app tooling checks.
* **Queue**: filename-consistent dispatch order; pause waits for cooperative
  worker halt; optional **Job ID** column in Settings.
* **Planning**: batch sizing uses free scratch-disk and RAM-disk headroom when
  configured.
* **Robustness**: FFmpeg decode/hwaccel fallbacks, scene-detect and encode
  tweaks; batched resume rehydrates segments so validate succeeds after
  interruption.
* **GUI**: refreshed window icon.

## Known limitations (same themes as beta-1)

* `02_sample_bench` real implementation (smart auto-tuning) — post-beta.
* `av1_nvenc` → `hevc_nvenc` automatic fallback on encode failure.
* macOS / Linux ports.
* Out-of-process worker broker (today everything runs in-process; the
  service layer is already abstracted for the eventual move).
* Code-signed Windows installer.

## Hardware

Optimized for NVIDIA RTX 3000-series and newer (CUDA / NCNN-Vulkan / TensorRT).
Older NVIDIA cards work for the CPU-encoder presets (libx264/libx265). NVENC
AV1 requires Ada-class (RTX 4000+) hardware.

## How to tag this release

```powershell
git checkout main
git pull
git tag -s v1.0.0-beta2 -m "AEP 1.0.0-beta2"
git push origin v1.0.0-beta2
```

The `release.yml` GitHub Actions workflow then builds the sdist + wheel and
attaches them to the auto-created Release page (marked as a pre-release).

The Windows installer (`AEP-Setup-1.0.0-beta2.exe`) is built locally with
`python scripts/build_installer.py` and uploaded manually to the release.
