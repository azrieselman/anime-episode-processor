# AEP 1.0.0-beta3

Third public beta of Anime Episode Processor — a 100% local Windows desktop app
for upscaling, frame-interpolating, and re-encoding anime episodes with full
preservation of subtitles, chapters, attachments, fonts, and metadata.

> **Beta** means: the pipeline remains feature-complete with a growing unit test
> suite on Windows, but field coverage is still limited. Please file bugs at the
> issue tracker — see `Help → Report Issue` in the GUI.

## Downloads

* **`AEP-Setup-1.0.0-beta3.exe`** — Windows installer (recommended for end
  users). Lightweight (~75–150 MB depending on bundle); on first launch the GUI
  offers to download and SHA256-verify the pinned third-party tools (~2 GB) into
  `%LOCALAPPDATA%\AEP\tools\`.
* **`anime_episode_processor-1.0.0b3-py3-none-any.whl`** — Python wheel for
  pip install. Run `python scripts/fetch_tools.py` afterward (or just launch
  `aep-gui` and let it fetch on its own).
* **`anime_episode_processor-1.0.0b3.tar.gz`** — sdist.

## Highlights since 1.0.0-beta2

* **Anime4K-legacy (2.5.x)**: new upscaler engine using the directory-batch
  `Anime4KCPP_CLI` path — fewer per-frame process spawns and faster GPU reuse on
  long episodes. CUDA-first with OpenCL fallback.
* **Anime4KCPP 3.2**: updated default balanced preset (ARNET F8B8 HDN), repinned
  CLI bundle, and improved adapter logging for very long command lines.
* **Decode**: MJPEG intermediate frames by default in balanced preset (faster
  scratch I/O than libpng); hardware decode respects preset-pinned `hwaccel` while
  Settings → **Auto** still applies the global D3D11VA/CUDA preference.
* **FFmpeg scdet scene detect**: optional downscale-before-detect (`ffmpeg_scdet_scale_width`,
  default 320 px) for faster scene-cut analysis when using the FFmpeg backend.
* **Robustness**: decode-stage hwaccel fallback chain, broker/plan wiring for
  intermediate codec and hwaccel merge, and expanded unit coverage.

## Known limitations (same themes as beta-2)

* `02_sample_bench` real implementation (smart auto-tuning) — post-beta.
* `av1_nvenc` → `hevc_nvenc` automatic fallback on encode failure.
* macOS / Linux ports.
* Out-of-process worker broker (today everything runs in-process; the
  service layer is already abstracted for the eventual move).
* Code-signed Windows installer.

## Hardware

Optimized for NVIDIA RTX 3000-series and newer (CUDA / NCNN-Vulkan / TensorRT).
Older NVIDIA cards work for the CPU-encoder presets (libx264/libx265). NVENC
AV1 requires Ada-class (RTX 4000+) hardware.

## How to tag this release

```powershell
git checkout main
git pull
git tag -s v1.0.0-beta3 -m "AEP 1.0.0-beta3"
git push origin v1.0.0-beta3
```

The `release.yml` GitHub Actions workflow then builds the sdist + wheel and
attaches them to the auto-created Release page (marked as a pre-release).

The Windows installer (`AEP-Setup-1.0.0-beta3.exe`) is built locally with
`python scripts/build_installer.py` and uploaded manually to the release.
