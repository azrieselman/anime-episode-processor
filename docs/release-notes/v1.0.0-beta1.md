# AEP 1.0.0-beta1

First public beta of Anime Episode Processor — a 100% local Windows desktop app
for upscaling, frame-interpolating, and re-encoding anime episodes with full
preservation of subtitles, chapters, attachments, fonts, and metadata.

> **Beta** means: the pipeline is feature-complete and 349 unit tests pass on
> Windows, but the code is freshly off rc2 and there's no community stress
> tests yet. Please file bugs at the issue tracker — see `Help → Report Issue`
> in the GUI.

## Downloads

* **`AEP-Setup-1.0.0-beta1.exe`** — Windows installer (recommended for end
  users). Lightweight (~150 MB); on first launch the GUI offers to download
  and SHA256-verify the pinned third-party tools (~2 GB) into
  `%LOCALAPPDATA%\AEP\tools\`.
* **`anime_episode_processor-1.0.0b1-py3-none-any.whl`** — Python wheel for
  pip install. Run `python scripts/fetch_tools.py` afterward (or just launch
  `aep-gui` and let it fetch on its own).
* **`anime_episode_processor-1.0.0b1.tar.gz`** — sdist.

## What's in the box

* **GUI** (PySide6): Queue, Job Config, Stream Inspector, Preset Designer,
  Logs, Settings, Verify Tools dialog. Drag-and-drop a folder full of
  episodes, pick a preset, click Start Queue.
* **CLI**: `aep-cli probe / list-presets / enqueue / list-jobs` for headless
  use; `aep-worker` for synchronous single-job runs.
* **Pipeline**: probe → plan → scene-detect → batched
  decode/upscale/interpolate/postprocess/encode → mux → validate. Resumable
  and content-addressed via the cache layer.
* **RAM-disk routing**: frame-heavy stages and per-batch encode segments
  transparently route to a configured RAM-disk when there's enough headroom.
* **Batched pipeline**: long videos are split into time-bounded chunks, each
  run end-to-end on the RAM-disk, then concat-muxed at the end.
* **Encoders**: `hevc_nvenc`, `h264_nvenc`, `av1_nvenc` (Ada+),
  `libx264`, `libx265`.
* **NCNN-Vulkan upscalers**: Real-CUGAN, Real-ESRGAN, waifu2x.
* **Frame interpolation**: RIFE with scene-cut handling (no morphed
  transitions across hard cuts).
* **Stream preservation**: audio, subtitles, chapters, attachments, fonts,
  global metadata, per-stream metadata, and dispositions are preserved by
  default through MKVToolNix.

## Known limitations (not blockers for beta-1)

* `02_sample_bench` real implementation (smart auto-tuning) — post-beta.
* `av1_nvenc` → `hevc_nvenc` automatic fallback on encode failure.
* macOS / Linux ports.
* Out-of-process worker broker (today everything runs in-process; the
  service layer is already abstracted for the eventual move).
* Code-signed Windows installer.

## Hardware

Optimized for NVIDIA RTX 3000-series and newer (CUDA / NCNN-Vulkan / TensorRT).
Older NVIDIA cards work for the CPU-encoder presets (libx264/libx265). NVENC
AV1 requires Ada-class (RTX 4000+) hardware.

## How to tag this release

```powershell
git checkout main
git pull
git tag -s v1.0.0-beta1 -m "AEP 1.0.0-beta1"
git push origin v1.0.0-beta1
```

The `release.yml` GitHub Actions workflow then builds the sdist + wheel and
attaches them to the auto-created Release page (marked as a pre-release).

The Windows installer (`AEP-Setup-1.0.0-beta1.exe`) is built locally with
`python scripts/build_installer.py` and uploaded manually to the release.
